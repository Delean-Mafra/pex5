# CURSO DE CIÊNCIA DE DADOS

# PROJETO DE EXTENSÃO V – CONSTRUÇÃO E EXECUÇÃO PRELIMINAR DO PROJETO

## DESCRIÇÃO

Nesta etapa, o(a) estudante de **Ciência de Dados** deve **consolidar** e **estruturar**, de forma **detalhada**, um projeto de intervenção social, tecnológica ou educacional aplicado ao universo do **Data Science**.

Com base nas fases anteriores do ciclo de extensão e nos conteúdos do PPC, este momento visa transformar ideias, pesquisas e análises preliminares em um **plano de ação** robusto, abordando desde a **coleta e tratamento de dados** até a **construção de modelos analíticos ou preditivos** e a **validação** de resultados.

O projeto deve contemplar:

- Objetivos gerais e específicos
- Justificativa
- Critérios de avaliação
- Recursos necessários
- Cronograma
- Métodos
- Teste piloto

Dessa forma, assegura-se a aplicação de conceitos de:

- Estatística
- Programação
- Engenharia de Dados
- Aprendizado de Máquina
- Áreas correlatas

em situações reais, beneficiando diretamente uma comunidade, instituição ou empresa parceira.

Finalmente, quando possível e apropriado, o(a) estudante poderá promover palestras ou treinamentos sobre temas de Ciência de Dados, como:

- Análise exploratória
- Visualização de dados
- Engenharia de features
- Modelos de Machine Learning
- Ética e privacidade de dados

---

## O QUE REALIZAR

Para iniciar seu projeto:

1. Preencha a **Carta de Apresentação**.
2. Escolha uma organização (empresa, comércio, templo, escola etc.).
3. Após obter autorização formal por meio do **Termo de Autorização para Realização das Atividades Extensionistas**, inicie o projeto.
